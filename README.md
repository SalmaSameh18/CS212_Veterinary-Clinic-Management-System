# CS212_Veterinary-Clinic-Management-System
A C++ Veterinary Clinic Management System using Data Structures to manage pets, medical records, and clinic visits.

## 1. Project Overview

The Veterinary Clinic Management System is a console-based C++ application designed to help manage a veterinary clinic.

The system allows users to register pets, manage their information, search for pets, organize the waiting queue, and keep track of recent visits.

## 2. Main Features

- Register new pets.
- Delete pet records.
- Search for pets using their unique ID.
- Display all registered pets.
- Update pet information.
- Add pets to the waiting queue.
- Call the next pet for examination.
- View recent visit history.
- Manage pet medical records.

## 3. Data Structures Used

This project manually implements the following data structures:

- **Linked List:** Stores and manages pet medical records.
- **Binary Search Tree (BST):** Supports pet lookup using Pet ID.
- **Queue:** Organizes pets waiting for examination using FIFO.
- **Stack:** Stores recent completed visits using LIFO.

## 4. Technologies Used

- C++
- Object-Oriented Programming
- Data Structures
- Visual Studio Code

## 5. How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure a C++ compiler (such as GCC) is installed.
4. Compile the source files.
5. Run the generated executable.

Example compilation command (adjust the filenames if needed):
```
g++ *.cpp -o VeterinaryClinic
```

Run the application:
```
./VeterinaryClinic
```

On Windows, run:
```
VeterinaryClinic.exe
```
